# Premier Gutters and Exterior

This repo deploys to Netlify (site premier-gutters-and-exterior) from the root of `main`, with no build step (netlify.toml), and serves
https://premierguttersandexterior.com.

**Live since 8 Oct 2026: the launch build.** Written by `deploy/production/export.py` in ~/Desktop/Premier Gutters v2 from the v2 MVP, and
pushed by `deploy/netlify-home/ship.py --production --push --netlify`; don't edit these files by hand. Every page is indexable, with its
canonical on https://premierguttersandexterior.com; sitemap.xml, robots.txt, llms.txt, _redirects (the old Wix addresses) and _headers are at
the root. The estimate forms post to Netlify Forms ("estimate"); the site's form notifications email the office.

The first site's files are in this repo's history (before 4 Oct), and its source is ~/Desktop/DeeAnn Gutters.
