Replacement windows for Lubbock homes

The windows we install are vinyl, made locally, with Low-E glass. They come with or without grids, in a color you pick or one that matches your other windows.

Not sure which style suits each room? Call us and we’ll help you choose.

Single-hung windows

Two sashes, one above the other. The bottom one slides up to open, and the top one stays fixed.

Double-hung windows

Two sashes that both slide, so you can open the window at the bottom, the top or both.

Picture windows

A large window that doesn’t open. With no sash to break it up, it gives a clear view and plenty of light.

Casement windows

A window hinged at one side that cranks open outward, like a door. The whole window opens to let air in.

Bay windows

Three windows that angle out from the wall, usually a wide one between two narrower ones, making a nook inside the room.

Window installation, start to finish

From measuring to cleaning up, here’s what to expect when we install your windows.

  1. 1Measure

    We measure every window you’re replacing, so each new one is made to fit its opening.

  2. 2Order

    We order your windows in the style and color you pick, made locally with Low-E glass.

  3. 3Remove

    On install day, the crew takes out your old windows and gets each opening ready.

  4. 4Install

    We set each new window in its opening, level and square, and fasten it in place.

  5. 5Seal

    We seal around each frame, so water, air and dust stay out.

  6. 6Trim

    We fit trim around each window to cover the gaps at its edges.

  7. 7Clean up

    Before the crew leaves, they clean up after the install.
